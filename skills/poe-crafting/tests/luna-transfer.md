# 千智杖製裝轉交

## 先給結論

- **A 可以從白色 i82 塑者 Imbued Wand 開始，但不能直接點改造。** 先用蛻變石變魔法，再用改造石；3000 顆可作為「洗單一塑者智慧電傷核心」的停損上限。依案例 i82 約 1/970，3000 次命中機率約 **95.47%**，不是雙核心成品的保證。
- **B 先停在目前狀態。** 3前3後已滿，沒有位置放「前綴無法被變更」，所以不能直接鎖前、洗後綴，也不能直接工藝攻速／本地暴擊。保留它當雙核心＋抗性／敏捷成品，或承擔失去核心的隨機重做風險；不要把 13D 當成必須追加投入的理由。
- **C 是可救的路線。** 2前3後有一個空前綴，可用 Farric Wolf Alpha「加前綴、移除隨機後綴」先騰出後綴；成功後再鎖前洗後，最後多工藝＋攻速＋本地暴擊。Wolf 加出的前綴是隨機，且每一步都要讀回物品狀態。
- **D 不能保證 20D 完成。** 依提供報價，已知固定支出是 **12.5D**，表面餘額 **7.5D**；但改造、覺醒後詞綴、Wolf、工藝和失敗重做都有隨機或缺價項。這只能是單次路線的成本上限草案，不是成品保證。

## A：白色、未污染、塑者、i82 Imbued Wand

### 下一步

1. 先確認物品文字仍是 **普通／白色、塑者、Imbued Wand、物等 82、未污染**。
2. 使用蛻變石把白底變成魔法物品；改造石只作用於魔法物品。
3. 用改造石洗「每 10 智慧、武器攻擊附加閃電傷害」這個塑者前綴。3000 顆到上限就停；命中後保留並讀回實際詞綴與稀有度。
4. 不要把這把杖的改造概率套到尊師供體。供體要另外確認：只有目標尊師「每 16 智慧增加法術傷害」核心，且物等至少 68、同為法杖類。
5. 以覺醒者之玉合併時，先點會被消耗的尊師供體，再點要保留基底與物等的塑者杖。合併後立即重數前後綴；其他詞會重新生成，不能期待原本攻速或工藝被保留。

### 成本與停損

- 已知改造成本：3000 × 0.25c = **750c = 1.5D**。
- 3000 次的 95.47% 是單階段、約 1/970、獨立且機率不變的模型；失敗時不等於整條雙核心路線仍有 95.47%。
- 先取得供體與覺醒者之玉的實際報價，再決定是否合併。沒有供體詞綴／價格資料，不能宣稱這條路線在 20D 內完成。

## B：3前3後，已花 13D

目前詞綴：

- 前綴：每 10 智慧電傷／每 16 智慧法傷／最大魔力
- 後綴：火抗／冰抗／敏捷

### 可執行選擇

- **保守選擇：直接使用。** 雙智慧核心和三條後綴已在杖上；若攻速／本地暴擊不能缺，這件目前不是目標成品，但可以停止追加支出。
- **不要直接鎖前。** 3前3後時，鎖前綴本身要佔一條後綴，沒有空位，操作不合法。
- **不要直接工藝攻速／本地暴擊。** 後綴已滿，工藝台沒有位置。
- **高風險選擇：另行重做或隨機移除。** 無效石等操作可能移除雙智慧核心或最大魔力；它們的實際成本與成功率未提供，不能列成保證路線。若不能接受失去 13D 成果，就不要在 B 上試。

### B 的判斷

剩餘 7D 不會自動讓這件 3前3後變成可鎖前的狀態。這件最合理的停損是保留；要攻速／暴擊，優先處理 C 或另買／另做新素材。

## C：2前3後，雙核心＋火抗／冰抗／敏捷

這是有空前綴的救後綴狀態。

### 推薦路線

1. 先確認前綴確實只有雙智慧核心，後綴確實為火抗／冰抗／敏捷，且沒有隱藏工藝、破裂、污染或其他不可預期狀態。
2. 使用 Farric Wolf Alpha 的「加前綴、移除隨機後綴」配方，前提是該季配方與物品狀態在遊戲內可用。結果應是 **3前2後**：隨機新增一條前綴，隨機移除一條後綴。這一步可能移除三條後綴中的任何一條，不能指定留下哪兩條。
3. 若得到 3前2後，且還有空後綴，工藝「前綴無法被變更」花 **2D**，再用洗白石清除未受保護的後綴；先看遊戲內提示確認保護工藝的行為，完成後移除保護工藝。洗完後重新讀回，確認三個前綴仍在。鎖前是保護已有前綴，不是保證新增攻速或暴擊。
4. 移除保護工藝後，使用多工藝 **2D**，再加本地攻速與本地暴擊率兩條工藝。多工藝佔一條後綴，所以最後要確認有足夠後綴空間：多工藝＋攻速＋暴擊 = 3 條後綴。
5. 任一步驟若結果不是預期的 3前／可用後綴空位，停止並重新計算；不要照原計畫連續點下去。

### C 的風險與成本

- Wolf 的實際價格未提供；它不是免費材料，也不是必定保留指定抗性的公式。
- 2D 鎖前＋2D 多工藝只是已知工藝費；Wolf、洗白／重洗、攻速／暴擊工藝、底材與失敗重做另計。
- 如果攻速或本地暴擊其中一條可接受為非 T1 工藝，先依實際工藝台費用比較「直接保留現狀」與「救後綴」，不要為了完美詞綴自動追加。

## D：20D 算術檢查

依使用者指定的新報價：1D = 500c、改造 0.25c、覺醒 1500c；兩件素材合計 4D；準備 3000 改造、一次覺醒、鎖前 2D、多工藝 2D。

| 項目 | 算式 | 已知成本 |
|---|---:|---:|
| 兩件素材 | 已提供 | 4D |
| 3000 改造 | 3000 × 0.25c ÷ 500 | 1.5D |
| 一次覺醒 | 1500c ÷ 500 | 3D |
| 鎖前 | 已提供 | 2D |
| 多工藝 | 已提供 | 2D |
| **已知合計** |  | **12.5D** |
| **20D 表面餘額** | 20 − 12.5 | **7.5D** |

這 7.5D 必須同時涵蓋蛻變／富豪或其他合法轉換、Wolf、洗白或重洗、攻速和本地暴擊的實際工藝費、品質或其他材料、交易差額，以及改造未中或覺醒後狀態不適合收尾時的損失。題目沒有這些單價，也沒有雙核心覺醒結果的分布，因此不能稱「保證 20D 完成」。

### 建議的 20D 停損規則

- 每一階段記錄累計支出；下一步前保留足夠收尾額，不把 7.5D 全部視為可繼續賭的資金。
- 3000 改造未命中就停止這次 A 路線，不用「再一點點」突破上限。
- 覺醒後若是 3前3後，按 B 停止；不要硬塞鎖前。
- 覺醒後若是 2前3後，才按 C 評估 Wolf；先查 Wolf 與重洗材料的實際成交價。
- 只有實際物品狀態、每項材料價格、可接受的攻速／暴擊階級都確認後，才能重新做一次「剩餘預算是否足夠」的算術；仍不能把隨機製裝稱為保證。

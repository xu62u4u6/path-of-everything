# 千智攻擊法杖：20D 研究案例

查核：2026-09-27，預設國際服 PC Allflame trade。聯盟／用途尚未由使用者確認。此案例的 20D 是從零購料的總支出上限；不是保證做出任意六 T1 杖。

## 先確認你要什麼

雙核心目標：塑者「每 10 智慧，武器攻擊附加 1 至 (5–6) 閃電傷害」＋尊師「每 16 智慧增加 1% 法術傷害」。都是前綴、最低物等 68，family 分別為 AddedLightningDamagePerIntelligence 與 SpellDamagePerIntelligence，互不相同。底材先以 Imbued Wand 作攻擊杖候選。

注意：這不是直接給角色 1,000 智慧的杖。「法術傷害」要有技能／天賦的轉用機制才對攻擊有效；未知 build 時不能宣稱 DPS 提升。若第二詞對 build 沒有效益，便宜的單電傷核心＋攻速／暴擊可能更適合。用 PoB 比較，不預設雙核心一定值得。

來源：[當季 Wands 詞綴資料](https://poedb.tw/us/Wands)。資料藏在頁面內嵌 JSON；避免把合成隱性詞誤當勢力前綴。

CoE beta 實測：Shaper Imbued Wand，魔法，改造石，唯一需求為上述電傷前綴；i82 約 1/970，i68 約 1/877。只洗改造，沒有把增幅策略計入。i82 平均 970 顆約 0.389D；3,000 顆花費 1.204D，依四捨五入的 1/970 模型約 95.47% 會命中；不是整條路線 95.47%。降低物等會失去其他高階詞機會，不能無條件推薦。

後續 CoE 實測：i68 Elder Driftwood Wand，魔法，改造石，唯一需求為每 16 智慧法傷，約 1/228。平均改造費 35.568c（0.0915D）；1,000 顆封頂 156c（0.401D），單階段約 98.77% 命中。可比較「空尊師供體價格＋0.401D 材料上限」與洗好供體價格，別為單個普通階級的目標詞盲付 2D。若兩件皆自洗，兩個改造階段各自到上限的聯合成功率約 94.29%（i82 塑者 3,000 次與 i68 尊師 1,000 次、獨立假設），仍不包含覺醒後收尾成功率。

## 主路線：兩核心，先完成可用版

1. 比較成品／半成品價格。購料暫定上限：塑者 Imbued Wand 2D、已洗好且只有一個尊師勢力詞的供體法杖 2D；兩者物等至少 68，接收杖依用途選 i68 或 i82。上限是買入條件，不能當市場報價。原料便宜時也可比較白底＋塑者／尊師崇高石；施加前檢查該通貨對基底狀態的限制，施加後還要計入清洗。
2. 接收杖洗成魔法，以改造命中電傷／智慧，最多 3,000 顆。留普通後綴不妨礙覺醒，但若另有勢力詞，不能直接合。碰到上限未中就停，不繼續無限重試。尊師供體可比較自洗：此次 CoE 已測 i68 Elder Driftwood Wand 約 1/228；其他底材／物等需重算，不可把塑者 1/970 套到尊師。
3. 核對供體唯一勢力詞為法傷／智慧、接收唯一勢力詞為電傷／智慧。覺醒者先點尊師供體，再點塑者 Imbued Wand。產生雙勢力稀有杖，保留兩核心；其餘重洗。
4. 看實際結果選擇：
   - 後綴有夠用攻速／暴擊且仍能補缺項：直接單工藝收尾，省 4D；已有工藝與空位仍須核對。
   - 至少一空後綴且需重做後綴：上前綴鎖 2D → 洗白 → 多工藝 2D → 工藝攻速＋本地暴擊率。原前綴保留，三條後綴就是多工藝與兩條工藝。若已有可接受後綴，不必強行清掉。
   - 2 前／3 後：可比較 Farric Wolf Alpha 加前刪後的當季成本，騰空後綴後走上鎖收尾；先查合法性與費用。
   - 3 前／3 後：不能上鎖或加前刪後。先保留兩核心現狀並回報是否已可用；若缺必要攻速／暴擊，這次沒有完成目標。重作或無效石都另有成本／失去核心風險，不自動執行。
5. 上限規劃：兩底材／供體合計最多 4D＋改造 1.204D＋覺醒 2.623D＋锁前／多工藝 4D＝11.827D。其他材料／單工藝／救後綴暫留 1D，但須報價確認能涵蓋。餘約 7.173D 留作停損緩衝；不是自動授權第二次完整重做。每次重試先重算已花費＋下一次成本＋收尾保留額 <=20D。未完成時也不可把這個上限說成成功保證。

## 收尾工藝的具體候選

此次 PoEDB 查到法杖可用的普通工藝：11–13% 攻速，4 崇高石；25–27% 本地暴擊率，4c。以快照崇高石 2.55c 算，兩條共 14.2c（約 0.0365D），另加洗白等。不要誤選法術暴擊率或近戰限定的攻速高階工藝。工藝需已解鎖；未解鎖的取得成本／時間也要處理。

來源：[Attack speed 工藝表](https://poedb.tw/us/Attack_speed)、[Helena 工藝表](https://poedb.tw/us/Helena)。實際遊戲工藝台若不同，以當季查核修正。

## 便宜候選：一核心即可用時

只做塑者電傷／智慧，保留攻速＋暴擊工藝；明確少了第二個核心，不可拿來冒充雙核心目標。

改造命中後，先看有無好後綴；富豪升稀有。如果後綴值得留且可單工藝補缺就收尾。若需清後綴，可在仍有空前綴時用 Farric Wolf Alpha 加前刪後，最多兩次即可清掉最多兩個原後綴而不刪電傷前綴，再多工藝＋攻速＋暴擊。每次檢查實際空位；只要詞綴狀態不符合這個簡單富豪起始條件，就重新分析。

此候選通常少了覺醒與鎖前成本，但仍需底材及野獸報價，不能稱已實證最低價。使用者要求兩核心時僅作備選，不擅自改目標。

## 執行預算腳本

`python3 scripts/cost.py references/wand-budget.json`

輸入：聯盟、含時區報價時間、來源、chaos_per_divine、budget_divine、items（name／quantity／unit_chaos；未知用 null）。可附 trial（success_probability／attempt_cap）計算單階段獨立重試。不會自動加成本，attempt_cap 對應的材料仍要放進 items。

範例故意保留缺價：輸出已知 7.827D、缺底材／供體／雜費，不能解讀為整把只需 7.827D。資料更新後重算，不沿用案例中的匯率。
